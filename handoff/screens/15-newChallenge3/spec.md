## 바꾸는 이유와 변경점
약정 금액과 멤버 선택, 경고문이 맨 아래에 몰려 있어서 무엇을 확정하는지 한눈에 보기 어려웠어요.
- [수정] 약정 금액(각자하기일 때만)과 함께할 모임원 선택. 나는 필수로 고정.
- [추가] 만들기 직전에 설정 요약을 보여줘요.
- [수정] "오늘 시작하면 수정 불가" 경고는 요약 바로 아래, 확정 직전에만.
- [유지] 참가자별 금액 다르게 설정 기능은 이후 단계로 미뤘어요(필요하면 요약 아래 토글로 추가).
모임원을 골라 보고 챌린지 만들기를 누르면 챌린지 탭으로 돌아가요.

## 데이터 · 상태 · 동작
penaltyPerDay(solo일 때만, 칩 1천/3천/5천/1만 + 기존 직접 입력 유지 가능), participants(나 필수 고정 + 모임원 토글), 요약, 오늘 시작 경고. "챌린지 만들기" → 기존 생성 API 호출 후 모임 챌린지 탭으로. 참가자별 금액 설정은 이 화면 요약 아래 토글로 두어도 됨.
