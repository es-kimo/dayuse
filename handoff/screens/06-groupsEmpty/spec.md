## 바꾸는 이유와 변경점
모임 만들기 버튼과 초대 코드 입력이 위아래로 두 번씩 나와서 뭘 눌러야 할지 헷갈렸어요.
- [수정] 빈 상태에서는 상단 버튼과 입력창을 숨기고, 가운데 한 곳에서 선택하게 했어요.
- [수정] "초대 코드로 가입"은 버튼이 아닌 바로 입력하는 칸으로.
- [유지] 데이유 캐릭터와 안내 문구.
코드를 아무거나 입력하면 들어가기 버튼이 켜져요.

## 데이터 · 상태 · 동작
모임 0개일 때 상단 "만들기" 버튼과 초대코드 입력줄을 숨기고 가운데 빈 상태 하나만. 코드 입력 시에만 "들어가기" 활성.
