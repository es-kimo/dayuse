# 11 새 챌린지 만들기

- 라우트: `/groups/:id/challenges/new`
- 기존 페이지(추정): `NewChallengePage`
- 참고: `mock.png`(눈으로 확인), `mock.html`(구조·문구). mock.html의 `<i data-icon="X">`는 lucide-react `X`, `<i data-dayu="색" data-face="표정">`은 `<DayuAvatar color face />`(data-bare면 `<Dayu />`).

## 바꾸는 이유와 변경점
항목 11개가 한 화면에 이어져서 스크롤이 길고, 어디까지 했는지 알기 어려웠어요.
- [수정] 3단계로 나눴어요: 무엇을 → 언제·얼마나 → 누구와. 상단에 진행 막대.
- [추가] 인증 기준 예시를 눌러서 채울 수 있게 했어요.
- [추가] 마지막 단계에 설정 요약을 보여주고 확인하게 했어요.
- [수정] "오늘 시작하면 수정 불가" 경고는 요약 바로 위, 확정 직전에만.
- [유지] 기간 추천 칩, 각자하기/함께하기 카드, 약정 금액 칩, 멤버 선택.
제목을 입력하고 다음으로 3단계까지 넘어가 보세요.

## 데이터 · 상태 · 동작
3단계 위저드. step1 제목·설명·인증기준(+예시 칩) → step2 기간 칩·주기(매일/주N회 스테퍼)·방식(각자/함께) → step3 약정 금액(각자하기만)·멤버 선택(나 필수)·요약 + 오늘 시작 경고. 하단 이전/다음 고정, step1은 제목·기준 입력 전 다음 비활성. 기존 폼 상태/검증 로직은 그대로 두고 화면만 단계로 나눈다.
