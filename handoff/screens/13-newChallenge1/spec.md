## 바꾸는 이유와 변경점
항목 11개가 한 화면에 이어져서 스크롤이 길고, 어디까지 했는지 알기 어려웠어요. 3단계 중 첫 번째예요.
- [수정] 1단계는 "무엇을"만: 챌린지 이름, 설명(선택), 인증 기준.
- [추가] 인증 기준 예시 칩을 누르면 바로 채워져요.
- [유지] "기존 내용 불러오기"는 "지난 챌린지 불러오기" 버튼으로 제목 옆에 두었어요.
- [수정] 이름과 인증 기준을 채워야 다음 버튼이 켜져요. 상단 진행 막대 1/3.
이름을 입력하고 예시 칩을 누른 뒤 다음을 눌러 보세요.

## 데이터 · 상태 · 동작
title(필수), description(선택), criteria(필수) + 예시 칩. "지난 챌린지 불러오기" = 기존 "기존 내용 불러오기" 기능 연결. 제목·기준 입력 전 다음 비활성. 폼 상태는 3단계가 공유(상위 컨텍스트/스토어) — 단계 이동 시 값 유지.
