## 바꾸는 이유와 변경점
빨간 박스 안에 경고 세 줄이 빼곡해서 읽기 부담스러웠고, 제목만으로는 되돌릴 수 없다는 게 잘 안 보였어요.
- [수정] 제목을 질문으로: "챌린지를 중단할까요?" 아래에 챌린지 이름과 참여자 수.
- [수정] 경고는 아이콘이 붙은 세 줄로: 남는 것 / 빠지는 것 / 되돌릴 수 없음.
- [수정] 버튼은 "계속 진행"(안전한 쪽)과 "중단하기"(빨강).
- [추가] 중단 이유가 참여자에게 보인다는 걸 라벨에 적었어요.
- [추가] 챌린지 상세 오른쪽 위 더보기(⋮)에서 열려요. 모임장에게만 보이는 전제예요.

## 데이터 · 상태 · 동작
challengeTitle, participantCount, reason(선택, 200자, 참여자에게 공개). "계속 진행"=닫기, "중단하기"=중단 API 후 모임 챌린지 탭 + 토스트.
