# dayuse 문구 가이드 v1.0 (BR-02)

## 톤 원칙

1. **짧고 친근한 해요체.** "~합니다/~됩니다" 대신 "~해요/~돼요". 한 문장에 하나의 정보.
2. **버튼은 행동으로.** 명사+동사 2~4자 조합: "인증 올리기", "모임 만들기", "초대 링크 복사".
3. **비난·압박 금지.** 미인증·미납은 사실만 알리고 다음 행동을 제안해요. 탓하는 말, 비교, 재촉 표현을 쓰지 않아요.
4. **숫자는 정확하게, 감정은 담백하게.** 금액·날짜는 그대로 보여주고, 느낌표는 축하 순간에만 한 번.
5. **데이유 표정과 짝지어요.** 완료 = 해냈어요, 응원 = 응원해요, 미인증·빈 화면 = 쉬어가요 (슬프거나 화난 얼굴은 없어요).

## 쓰지 않는 표현

| 피하기 | 대신 |
|---|---|
| 실패했습니다 / 또 빠졌어요 | 오늘은 인증이 없었어요 |
| 아직도 인증 안 하셨나요? | 오늘 인증이 1개 남았어요 |
| 벌금이 부과되었습니다 | 정산할 금액이 생겼어요 |
| 불가합니다 / 할 수 없습니다 | ~은 바꿀 수 없어요 (+이유) |
| 오류가 발생했습니다 | 잠시 문제가 생겼어요. 다시 시도해 주세요 |
| 다른 멤버는 모두 완료했어요 | (비교 문구는 쓰지 않아요) |

| 상황 | 레이블 |
|---|---|
| 인증 시작 (카드·오늘 할 일) | **인증 올리기** (현재 "인증하기", "사진 찍고 인증하기" 통일) |
| 인증 제출 (시트 하단) | 인증 완료하기 |

| 챌린지 생성 | 챌린지 만들기 |
| 기록 공유 | 기록 공유하기 |
| 계좌 | 계좌 등록하기 |
| 입금 (멤버) | 입금 신고하기 |

## 현재 화면 문구 개선안

| 화면 | 현재 | 제안 |
|---|---|---|
| 모임 홈 | 모든 지난 기록이 완료되었습니다 | 지난 기록을 모두 확인했어요 |
| 모임 홈 | 미수행 확정 벌금 (미납) | 정산할 금액 |
| 모임 홈 | 모임원들이 입금할 모임 계좌를 먼저 등록해 주세요. | 멤버들이 입금할 계좌를 먼저 등록해 주세요 |
| 챌린지 상세 | 챌린지 시작일(00:00 KST) 이후에는 참여자 추가/취소 및 인증 기준 변경이 불가합니다. | 챌린지가 시작되면(00:00 KST) 참여자와 인증 기준은 바꿀 수 없어요 |
| 챌린지 상세 | 수행 진행 중 (약정·취소 고정) | 진행 중이라 참여를 바꿀 수 없어요 |
| 새 모임 | 생성자는 자동으로 모임장(HOST)이 됩니다. | 만든 사람이 모임장이 돼요 |
| 초대 | 이미 가입된 멤버입니다 | 이미 함께하고 있는 모임이에요 |
| 초대 | 모임장 류기현님의 초대를 받았습니다. | 류기현님이 모임에 초대했어요 |
| 오늘의 할 일 | 참여 중인 모든 모임의 오늘 인증 현황입니다. | 참여 중인 모임의 오늘 인증 현황이에요 |
| 알림 설정 | 하루 1회, 미인증 챌린지가 있을 때만 발송됩니다. | 인증할 챌린지가 남은 날에만 하루 한 번 알려드려요 |
| 알림 설정 | 아이폰에서는 홈 화면에 추가된 dayuse 앱에서만 알림을 수신할 수 있습니다. | 아이폰은 홈 화면에 dayuse를 추가해야 알림을 받을 수 있어요 |
| 인증 시트 | 오늘 실천한 소감이나 인증 한마디를 남겨보세요. | 오늘 한마디를 남겨 보세요 (선택) |

## 빈 화면 · 안내 · 오류

| 상황 | 표정 | 제목 | 설명 | 버튼 |
|---|---|---|---|---|
| 모임 없음 | 기본 | 아직 참여한 모임이 없어요 | 모임을 만들거나 초대 코드로 들어가 보세요 | 모임 만들기 |
| 오늘 할 일 없음 | 쉬어가요 | 오늘은 인증할 챌린지가 없어요 | 새 챌린지를 만들어 보세요 | 챌린지 만들기 |
| 오늘 모두 완료 | 해냈어요 | 오늘 인증을 모두 마쳤어요! | N개 챌린지 · N일 연속 | 기록 공유하기 |
| 어제 미인증 | 쉬어가요 | 어제는 인증이 없었어요 | 오늘 다시 이어가요 | 인증 올리기 |
| 입금 대기 없음 | 기본 | 확인할 입금이 없어요 | 입금 신고가 오면 여기에 보여요 | — |
| 사진 용량 초과 | — | 사진이 너무 커요 | 10MB 이하 JPG, PNG, WebP로 올려 주세요 | 다시 고르기 |
| 네트워크 오류 | — | 잠시 연결이 끊겼어요 | 인터넷 연결을 확인하고 다시 시도해 주세요 | 다시 시도 |
| 잘못된 초대 코드 | — | 초대 코드를 찾을 수 없어요 | 코드를 다시 확인하거나 모임장에게 새 링크를 받아 주세요 | — |
| 권한 없음 | — | 모임장만 할 수 있어요 | — | — |

오류 메시지는 색만으로 구분하지 않아요: 빨간 테두리 + 아이콘 + 문장을 함께 써요.

## 푸시 알림

- 미인증 리마인더: "오늘 인증이 1개 남았어요. 자정 전에 올려 주세요"
- 친구 인증: "김코딩님이 ‘매일 1알고리즘’을 인증했어요"
- 응원: "류기현님이 응원을 보냈어요"
- 연속 기록: "7일 연속이에요! 오늘도 해냈어요"
- 입금 확인(멤버): "모임장이 입금을 확인했어요"

알림에는 친구 이름 외의 금액·벌금 정보는 넣지 않아요 (현재 정책 유지).
